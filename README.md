## 📖 Project Overview

The **Message Intelligence System** demonstrates a complete text-classification workflow:

**Raw Messages → Data Preprocessing → NLP Processing → Feature Extraction → ML Model → Prediction → Streamlit Deployment**

The project combines Natural Language Processing with Machine Learning to build an interactive message-classification application.

---

## 🎯 Objectives

- Clean and preprocess message data
- Apply NLP-based text preprocessing
- Convert text into numerical features
- Build a classification model
- Evaluate model performance
- Create an interactive Streamlit application
- Deploy the ML solution as a live web app

## 🧹 Data & Text Preprocessing

The project follows standard NLP preprocessing practices, including:

- Handling missing and duplicate data
- Text cleaning and normalization
- Tokenization
- Stop-word handling
- Preparing text for feature extraction
- Converting processed text into ML-ready features

---

## 🧠 NLP & Machine Learning

Text data must be transformed into numerical representations before being used by a machine-learning algorithm.

Common text-vectorization approaches include:

- Bag of Words
- TF-IDF Vectorization

The processed features are then used by a classification model to predict the appropriate message category.

---

## 📊 Model Evaluation

Classification performance can be evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

Precision, Recall and F1-Score are particularly useful for understanding classification errors beyond simple accuracy.

## 💻 Run the Project Locally

### 1. Clone the Repository

```bash
git clone https://github.com/maheshloharr/Message-Intelligence-System.git
```

### 2. Navigate to the Project

```bash
cd Message-Intelligence-System
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Environment

**Windows**
```bash
venv\Scripts\activate
```

**macOS / Linux**
```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Streamlit Application

```bash
streamlit run app_spam.py
```
